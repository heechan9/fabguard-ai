## 독립성 판정

- 제공 분할의 정상 source 시험 그룹 44/44가 정상 source 훈련 그룹과 겹치고, 시험 116구간 전부가 겹친 그룹에 있다. 시험 그룹을 전부 제거한 별도 민감도 실험의 훈련은 14그룹·214구간이지만 **시험 464구간 자체는 그대로**다.
- 정상 target 훈련 18개 그룹은 정상 target 시험 24개 그룹 중 18개와 겹친다. 정상 target 시험 116구간 중 **96구간**이 이 겹친 그룹에 속한다. 이 훈련 27구간은 현재 모델에 사용되지 않았으나, 나중에 target 적응·임계값 조정에 쓴다면 동일 그룹의 시험을 독립 평가라고 부를 수 없다.
- 저장된 시험의 이상 라벨은 이미 이전 모델 성능을 보는 데 사용됐다. 현재 저장 자료만으로 새 모델을 고른 뒤에도 손대지 않은 독립 이상 시험셋을 만들 수 있다는 근거는 없다. 훈련에 남은 정상 그룹을 검증용으로 떼더라도 독립 이상 탐지력은 입증되지 않는다.
- 서로 다른 세션 이름이 물리적으로 독립된 날짜·장비·설치·작업자였는지는 이 CSV만으로 확인할 수 없다. `recording_group`은 데이터 구조상의 분리 단위다.

## 강의 예제의 적용 범위

훈련 그룹과 검증 그룹을 나누고 전처리기를 훈련 데이터에만 적합하는 원칙은 유효하다. PR #162의 현재 파이프라인도 정상 source 훈련에만 결측치 대치·스케일링을 적합하므로, 예제를 복사해 넣는 것만으로 새 성능 개선이 생기지는 않는다. 예제는 `weight`와 `speed`를 함께 사용하지만 현재 로봇 특징 CSV에는 속도 열이 없다. [IMAD-DS 원출처](https://zenodo.org/records/12665499)는 로봇 팔의 운전 변화가 **하중**, 별도 브러시리스 모터의 운전 변화가 **속도**라고 구별한다. 로봇 평가표에는 확인된 하중·배경만 사용한다.

## 다음 실험의 사전 계약

1. 우선 **같은 로봇·동일 센서 정의**의 새 녹화를 확보한다. 기록 그룹 식별자, 취득 날짜, 장비, 하중, 배경 환경, 정상/나사 풀림 라벨의 생성 근거를 구간 추출 전에 기록한다. 재배포·사용 조건과 원본 해시도 고정한다.
2. 새 자료를 열기 전에 각 하중×배경의 정상·이상 **독립 녹화 그룹 수**를 표로 만들고, 가능한 조합과 결측 조합을 명시한다. 기존 464구간은 개발 과정에서 본 시험으로 표시한다. 새 자료에서 그룹 전체를 검증 또는 최종 평가에만 할당하며 겹치는 그룹은 제외한다.
3. 새 검증 자료가 충분하면 모델 후보(현재 IsolationForest와 사전 고정한 단순 기준선), 전처리, 임계값 선정 규칙, 주요 지표(AUROC·AP·정상 오경보·이상 포착 및 조건별 그룹 수)를 **최종 평가 전** 고정한다. 정상만으로 임계값을 조정한다면 이상 포착력은 별도의 잠금 평가에서 확인한다. 적은 그룹·한 종류 결함·인위적인 정상/이상 50:50 구성의 한계를 함께 표기한다.
4. 최종 평가 자료는 한 번만 열고 결과를 기록한다. 새 독립 녹화를 확보할 수 없다면 모델 비교는 탐색적 분석으로만 보고하고 성능 향상·현장 운용 주장은 하지 않는다.

PR #162의 병합 판단과 로봇 웹 연동은 이 후속 평가와 별개의 결정이다. 이 감사에서 병합, 모델 변경, 기존 시험셋 반복 튜닝은 수행하지 않았다.
