# SECOM 변수 분포 근거 보완 계약

2026-10-30 KST. 기준 main cce8360f. 5회차 강의 9·10·18·19쪽의 해석 원칙을 기존 근거 설명에 적용한다. 새 모델·평가 정의·분할·임계값·의존성 변경이 아니다.

## 계산 전에 고정한 범위

- 기존 final_model_importance.csv의 상위 5개를 그대로 설명한다: feature_059, feature_247, feature_519, feature_065, feature_475. 새 그룹 차이로 변수를 재선택/정렬하지 않는다.
- 기존 train_split.csv에 고정된 1,175개 ID만 통계·그림에 사용한다. 392개 시험 기록의 값·라벨은 통계에 사용하지 않는다. 테스트 노출 이력이 있는 기존 대표 성능은 그대로 둔다.
- 그룹: 0=Pass, 1=Fail. 원본 결측은 대치하지 않는다. 각 그룹의 전체 n·관측 n·결측 n/비율, 평균·표본표준편차(ddof=1)·5/25/50/75/95분위수를 보고한다.
- 차이 방향은 Fail - Pass다. 표준화 차이는 (Fail 평균 - Pass 평균) / 두 그룹 표본분산의 자유도 가중 pooled SD. 이는 설명용 그룹 차이이며 인과 효과나 예측 중요도가 아니다. 어느 그룹 관측 n<2 또는 pooled SD=0이면 null과 사유를 표시한다.
- 분포 비교는 두 그룹에 동일한 bin 경계를 사용하는 밀도 히스토그램·상자그림으로 제시한다. 시간별 표는 학습 자료의 달력 월 단위이며 새 모델 분할이 아니다. 그룹 n/관측 n을 함께 읽고 독립 표본/정상 안정성을 가정하지 않는다.
- p-value·새 성능·원인·실제 센서 이름은 산출/추정하지 않는다. 공정단위·물리단위 미확인. 강의 V60과 feature_059는 1-based/0-based 위치 대응일 뿐 물리적 의미를 보증하지 않는다.

Train에서 feature_112/247/385/519 네 변수의 결측 위치가 같다. 이는 결측률만 같다는 것보다 강한 관측 사실이지만, 값의 동일성·물리적 동일 센서·중복 변수 삭제를 뜻하지 않는다. 선택된5변수 순위도 바꾸지 않는다. Train의 동일 timestamp 중복은 첫 행 이후22건(해당 쌍을 포함하면44행)이다. timestamp만으로 중복 생산 건임을 확정하거나 행을 자동 삭제하지 않는다.

### feature_475: 극단값 민감도, 정제 권고 아님

[재현 가능한 민감도 JSON](review/session5-20261030/feature_475_sensitivity.json)은 각 그룹에서 최대 관측값 **한 건씩을 별도 복사본에서 제외**한다. 동률이면 고정 Train 순서의 첫 행만 제외한다. 두 시나리오는 서로 독립적이며 원래 요약·원본·모델 입력에는 적용하지 않는다.

| 설명 시나리오 | Pass 관측 n | Fail 관측 n | Fail - Pass 평균 차이 |
|---|---:|---:|---:|
| 원본 관측값 모두 유지 | 1091 | 80 | +0.562853 |
| Pass 최대39.3528 (`secom_0275`) 한 건 제외 | 1090 | 80 | +0.595014 |
| Fail 최대38.2143 (`secom_0634`) 한 건 제외 | 1091 | 79 | +0.140649 |

38.2143은 **Fail군 최대이지 전체 최대가 아니다**. Fail 최대 한 건에 평균 차이가 민감함을 드러내는 사후 진단이며 오류·삭제 필요성·성능 개선을 입증하지 않는다. 센서 단위·계측/공정 이력을 확인할 가설로 남긴다. 이상값 제거·winsorization·재학습·임계값 변경·새 중요도 순위는 하지 않았다.

### 관측값 EDA와 모델 입력을 구분

이 문서의 평균·표본SD·분위수·그림은 결측을 제외한 **observed-only 기술통계**다. 반면 기존 [모델 파이프라인](../src/fabguard/modeling.py)은 학습 폴드에만 적합한 품질 필터 후 중앙값 대치와 결측 indicator를 사용한다(로지스틱 경로는 추가 표준화). 대치 후 분포나 모델이 실제 소비한 값의 요약을 여기의 원본 관측 분포와 동일시하지 않는다. 대치값은 관측값으로 세지 않으며 이 설명을 위해 새 전처리/모델 fit도 하지 않았다.

관측 연관성은 추가 이력·독립 자료에서 확인할 가설이지 원인 확정이 아니다. 단위가 다른 익명 변수의 원시 평균 차이를 직접 비교하거나 중요도로 재정렬하지 않는다.
