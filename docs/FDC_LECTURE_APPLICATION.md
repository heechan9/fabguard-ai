## 경보 숫자를 읽는 공통 규칙

계산의 정본은 [파일별 report.json](review/pr173-validation-20261024/robot_spc_results/report.json)이다. 지표를 새로 계산하거나 임계값을 재조정하지 않는다.

| 방법 | 원시 경보 창 수 | 연속 경보 묶음 수 | 활동 분모 |
|---|---:|---:|---|
| Shewhart | 9 | 6 | 평가 가능 1,043창 |
| EWMA | 0 | 0 | 평가 가능 1,043창 |
| 양측 CUSUM | 3 | 2 | 평가 가능 1,043창 |

- 원시 경보는 임계값을 초과한 창 개수다. 묶음은 파일 안에서 연속된 경보 창의 집합이며, 비경보 창·평가 불가 창·파일 경계에서 끊긴다. 경보 뒤 통계량 리셋과 묶음 종료를 혼동하지 않는다.
- `alarm_activity_per_evaluable_window = raw_alarms / windows_evaluable`. 위 분모는 evaluation 7파일·2기록 그룹의 완전 창 1,043개이며 reference 1,788창·calibration 149창은 섞지 않는다. 파일 간 묶음을 합치지 않는다.
- 평가 가능 시간은 1,043 × 0.050초 = 52.15초다. 전체 원본 시간이나 독립 세션 수가 아니다. 마지막 미완성 꼬리 구간은 점수·분모에서 제외한다.
- 이번 실행은 완전 창의 제외 수 0이다. 일반 입력의 `windows_excluded`는 사유별 집계이므로 한 창의 복수 사유를 더해 제외 창 수로 쓰면 안 된다. 고유 제외 창 수는 `windows_complete - windows_evaluable`다.
- 창 보류: 결측/비유한·표본 부족·시간 공백·수치 범위 초과 등. 파일/실행 실패: 시간 역전·출처 해시 불일치·기준선/보정 실패 등. 상태와 사유는 보고서 원문을 따른다. 분모가 0이거나 방법이 unavailable이면 경보 0건으로 대체하지 않는다.
- 입력 계산 가능과 성능 평가 가능은 다르다. 정상성·독립 이상 정답·발생 시점 미확인으로 `false_alarm_rate`, `anomaly_recall`, `miss_rate`, `detection_delay`는 null이다. EWMA 0건은 우수성 근거가 아니다.
