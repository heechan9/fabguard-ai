## 허용하는 전달과 보류하는 전달

- **전달 가능:** 저장 결과 수치·검사 예산·누락 위험·원천 추적성과 문서상 비교 차단 이유.
- **보류:** 모델 운영 적합성, 실시간 판단, DRAM 제품/소자 해석, 실제 fab 기술 이전, 독립 일반화 성능.
- **추가 근거 필요:** 물리 변수 사전, lot/wafer/tool/recipe, 라벨 확정 시점, 실제 엔지니어 검토,
  독립 데이터와 승인된 실험 설계. 실제 제품 qualification 기준은 공장이 제공해야 한다.

## 재현 범위

[영문 전달서](TECHNICAL_HANDOFF_EN.md)의 표준 라이브러리 명령은 기존 저장 예측만 읽는다.
학습·모델 로딩·새 추론·임계값 선정·정본 결과 덮어쓰기를 하지 않는다.
파일 해시가 다르면 먼저 전달을 보류하고 변경 원인을 확인한다. 결과를 맞추기 위해 값을 고치지 않는다.

이 문서는 CPI의 검토 전달, MAE의 표준화, ATE의 전달 전 체크, RDA의 데이터 한계 설명을
연습한 기록이다. 반도체 실무 경력·DRAM 물리·전기검사·metrology 전문성을 대체하지 않는다.
Cpk/공정능력, 수율 개선율, MTTR/다운타임·비용 감소는 계산/주장하지 않는다.
