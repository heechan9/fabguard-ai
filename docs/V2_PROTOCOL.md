# FabGuard V2 독립 확인 프로토콜

상태: **사전 설계 · 실행 전**

이 문서는 V1 홀드아웃 노출 이후의 깨끗한 확인 경로를 고정한다. 독립 데이터와 승인자가
확보되기 전에는 V2 성능값을 만들지 않는다.

## 1. 진입 게이트

아래 조건을 모두 충족해야 평가를 시작한다.

1. [`EXTERNAL_DATA_QUALIFICATION.md`](EXTERNAL_DATA_QUALIFICATION.md)의 필수 항목을 통과한
   독립 제조 데이터가 있다.
2. V1 Train-CV만으로 생성한 모델 파일, 전처리기, 특징 순서, 설정과 SHA-256이 동결돼 있다.
3. 데이터 소유자 또는 권한 있는 검토자가 사용 범위와 라벨 정의를 승인했다.
4. 평가 실행자가 모델 개발 과정과 분리됐거나, 최소한 결과를 보기 전에 아래 판단 규칙에
   서명했다.
5. 데이터·모델·프로토콜 해시를 결합한 readiness 보고서가 PASS다.

하나라도 충족하지 못하면 `blocked`로 종료하며 점수를 생성하지 않는다.

## 2. 사전 고정 항목

| 구분 | 실행 전 고정 |
|---|---|
| 목적 | 자동판정이 아닌 위험순위의 독립 재현 여부 |
| 주지표 | Average Precision, Top-10% Fail capture, precision, lift |
| 보조지표 | Top-5%·20%, ROC-AUC, calibration, confusion matrix |
| 비교선 | 라벨 유병률에 해당하는 무정보 ranking 기준선과 승인된 기존 절차 |
| 분석 단위 | 중복되지 않은 물리적 생산 건 또는 사전 정의된 Lot 단위 |
| 불확실성 | 생산 건 또는 Lot 구조를 보존한 bootstrap 구간 |
| 누락 처리 | 임의 대체 금지; 동결 파이프라인이 처리할 수 없으면 실패 기록 |
| 종료 규칙 | 전체 적격 표본을 1회 평가하며 중간 결과로 모델·경계를 변경하지 않음 |

## 3. 실행 절차

1. 원본을 읽기 전 provenance·라이선스·스키마·라벨 계약을 확인한다.
2. 원본과 정규화 산출물의 SHA-256, 행 수, 시간 범위, 중복·결측 통계를 기록한다.
3. [`LOCKED_EVALUATION_CONTRACT.md`](LOCKED_EVALUATION_CONTRACT.md)의 readiness gate를 실행한다.
4. 동결 모델로 [`LOCKED_SCORING_CONTRACT.md`](LOCKED_SCORING_CONTRACT.md)의 단일 scoring을
   수행한다. 재학습·튜닝·특징 선택을 하지 않는다.
5. 사전 고정 지표, 분모, 불확실성 구간과 모든 실패를 함께 기록한다.
6. 사람 검토자가 결과와 주장 경계를 승인한 뒤에만 공개 요약을 갱신한다.

## 4. 판정

- **Confirmed:** 주지표가 무정보 기준선을 넘고, 불확실성·하위집단·시간구간 검토에서
  치명적 붕괴가 없으며 데이터 자격 위반이 없다.
- **Inconclusive:** 방향은 양호하지만 표본·Fail 수·불확실성 때문에 결론을 내릴 수 없다.
- **Not replicated:** 사전 고정한 주지표가 기준선을 넘지 못한다.
- **Invalid:** 누출, 중복, 라벨 정의 불일치, 권리 문제 또는 실행 후 규칙 변경이 발견됐다.

어떤 판정도 실제 수율 개선이나 인과효과를 뜻하지 않는다. 현장 효과는 별도의
[`CAUSAL_FIELD_VALIDATION.md`](CAUSAL_FIELD_VALIDATION.md) 프로토콜로 검증한다.

## 5. 변경 통제

결과 확인 후 모델·특징·전처리·지표·점검예산을 바꾸면 해당 실행은 탐색 실험으로 재분류한다.
다음 확인 실험에는 새 버전과 새로운 독립 데이터가 필요하다. 실패한 실행과 변경 이유는
삭제하지 않고 [`FAILURE_GOVERNANCE.md`](FAILURE_GOVERNANCE.md)에 따라 보존한다.
