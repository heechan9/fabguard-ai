# SMT 추가 검사실: 가상 시나리오

X-ray와 PCB 전기검사의 서로 다른 관찰 범위를 설명하는 교육용 체험이다. 기존 11단계 생산라인 옆의 독립된 UI이며 실제 장비 연결, 물리 시뮬레이션, AI 예측 모델이 아니다. 새 의존성·난수·학습 데이터가 없다.

## 가정과 판정

| 선택 사례 | X-ray | 전기검사 |
| --- | --- | --- |
| 이상 없는 사례 | 지정한 내부 빈 공간 없음 | 지정한 연결·분리 조건 만족 |
| 내부 빈 공간 | 빈 공간 표시, 검토 필요 | 연결 유지로 설정 |
| Open | 자료 없음 | 연결 끊김으로 설정 |
| Short | 자료 없음 | 이웃 회로 연결로 설정 |
| 자료 없음 | 판단 보류 | 판단 보류 |

X-ray 도식은 영상이나 재구성 결과가 아니며 빈 공간의 면적률·치수·합격 임계값을 추정하지 않는다. 전기검사 도식은 전압·저항 계산이 아니며 실제 장비 판정 알고리즘이 아니다. 납 부족/과열을 내부 결함이나 Open/Short의 필연적인 원인으로 연결하지 않는다. AOI 통과 여부로 추가 검사 결과를 결정하지 않는다.

기판 ID만 체험 대상으로 사용한다. 생산 회차 초기화, 대상 기판 변경, 사례 변경 시 이전 판정을 지운다. 같은 기판에 대한 UI 갱신은 판정을 유지한다. 체험은 기존 생산 상태·불량 건수·공정 내보내기·SECOM·국가별 근거를 수정하지 않는다.

## 참고 자료

2026-09-14 대화에서 확인한 한국공학대학교 공동기기원 공개 장비 목록에 기반한다. 장비 기능은 참고일 뿐 실제 데이터 접근, 대여, 내보내기 형식, API 지원은 확인하지 않았다.

- [3D X-ray XSCAN-9860A](https://cec.tukorea.ac.kr/equ/equInfo/equInfoDetail.hs?equCode=1248)
- [PCB 전기특성 검사 FA1282-01](https://cec.tukorea.ac.kr/equ/equInfo/equInfoDetail.hs?equCode=1148)

실제 연결은 기판·부품·검사 지점 ID, 시각, 검사 조건, 원본 영상/측정값, 전문가 판정과 기준을 확보한 뒤 별도 구현한다. 현재 CSV 양식은 기본 기록 준비용이며 영상·검사 지점 형식까지 확정한 계약이 아니다.

## 검증

`node --test tests/web/*.test.mjs`로 사례별 판정, 누락 보류, 잘못된 입력, 기판/사례/회차 초기화, 생산 상태 불변을 검증한다. 브라우저에서는 기판 선택 → 사례 선택 → 두 검사 실행 → 다른 기판 선택 → 처음부터 순서와 모바일 레이아웃을 점검한다.
