# 스마트공장 연계 설계와 KPI 경계

FabGuard V1은 UCI SECOM 공개데이터를 사용한 오프라인 위험순위화 프로토타입이다. 이 문서는 V1이 실제 스마트공장 정보 흐름에서 담당할 수 있는 위치와, 현재 증거로 말할 수 있는 성과의 범위를 구분한다. MES·FDC·검사시스템 연동이나 생산 성과는 구현하거나 검증하지 않았다.

## 목표 정보 흐름

| 단계 | 목표 역할 | V1 상태 |
|---|---|---|
| 설비·센서·검사 | 측정값과 품질 결과 생성 | SECOM의 익명 변수·라벨로 대체 |
| MES·FDC·검사시스템 | Lot·설비·공정·시간 식별자를 포함해 데이터 제공 | 연동 미구현 |
| FabGuard | 생산 건별 위험점수와 Top-K 점검 큐 생성 | 오프라인 구현 |
| 엔지니어 검토 | 변수 매핑, 4M, 변동점, 품질 이력을 대조해 후속 조치 결정 | 화면상 검토 절차만 제시 |
| 결과 기록 | 재검사·보류·설비점검·최종 품질 결과를 추적 | 피드백 저장 미구현 |

FabGuard는 PLC 인터록, 설비 제어 또는 자동 품질판정을 대체하지 않는다. 실제 확장 시에도 모델 출력은 승인 가능한 점검 큐로 제한하고 최종 조치 권한은 공정·품질 엔지니어에게 둔다.

## 증거 수준별 KPI

| 증거 수준 | 현재 사용 가능한 지표 | 해석 경계 |
|---|---|---|
| 모델 | PR-AUC, Fail recall, precision, balanced accuracy | 저장소의 고정 데이터·분할·실험계약 안에서만 해석 |
| 운영 시뮬레이션 | 점검 건수, Top-K Fail 포착률, lift, 누락 Fail | 실제 현장 점검시간·인력·비용을 측정한 값이 아님 |
| 제조 운영 | 불량률, 가동률, 리드타임, 의사결정시간 | 실제 MES·검사·작업 기록과 전후 또는 대조 검증 필요 |
| 사업 | 수율, 제조원가, 매출, 영업이익 | V1 결과에서 추정하거나 인과효과로 주장하지 않음 |

스마트제조 도입 연구에서 가동률, 생산량, 불량률, 제조원가, 리드타임, 의사결정시간과 정보공유가 성과지표로 사용된 사례는 FabGuard의 향후 현장 검증 항목을 설계하는 참고자료다. 해당 연구의 평균 효과는 FabGuard의 성능이나 기대 효과로 전용하지 않는다.

## 현장 도입 전 확인사항

- **사용자와 책임** - 공정·품질·설비 중 큐를 확인할 역할과 최종 승인자를 정한다.
- **식별자** - Lot, wafer, tool, chamber, recipe, 공정 단계와 측정시간을 추적 가능하게 연결한다.
- **변수 사전** - 측정 단위, 허용범위, 결측 의미, 센서 변경 이력과 공정 소유자를 관리한다.
- **라벨 계약** - Fail 판정 시점, 재검사 결과, 보류·폐기·재작업 상태를 일관되게 정의한다.
- **점검예산** - shift별 추가 점검 가능 건수와 우선순위 큐의 SLA를 정한다.
- **피드백** - 엔지니어 판단, 조치, 최종 결과를 모델 출력과 함께 감사 가능하게 기록한다.
- **지속 검증** - 데이터 드리프트, Top-K 포착률, 점검부담과 오경보를 기간별로 감시한다.
- **운영 통제** - 접근권한, 장애 시 기본 절차, 모델 버전, 변경 승인과 롤백 기준을 둔다.

도입 이후 성과는 단순 전후 변화만으로 FabGuard의 효과라고 해석하지 않는다. 무작위·단계적 도입 또는 자연실험과 이중차분을 이용한 대조 검증, 평행추세와 동시개입 점검은 [현장 인과효과 검증 계획](CAUSAL_FIELD_VALIDATION.md)에 정리했다.

## 설계 참고자료

- 스마트공장 정보계층에 관한 비공개 교육자료. MES·POP·ERP·SCM의 일반적 역할을 목표 아키텍처 정의에 참고했다.
- 이현진·김명건, `스마트공장 지원사업 주요내용 및 효과 분석`, 한국수출입은행 해외경제연구소, 2022. 스마트공장 구성요소, 도입·유지보수 부담과 성과 검증의 한계를 참고했다.
- 박양신·지민웅, `국내 중소·중견기업의 스마트제조 구축 실태와 성과`, 산업연구원 i-KIET 산업경제이슈 제81호, 2020. 스마트제조 성숙도와 공정·운영 KPI 구분을 참고했다.

원자료의 그림·표·예시 수치는 재배포하지 않는다. 위 자료는 학습 데이터, 모델 성능 근거 또는 FabGuard의 제조 성과 증거가 아니다.
