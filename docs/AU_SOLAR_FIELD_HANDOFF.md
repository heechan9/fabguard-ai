# 호주 솔라팜 자료의 FabGuard 적용 범위 (2026-10-23)

상태: **현장 검토 계약 초안; 실제 O&M 연동·현장 검증 없음**

개인 호주 워홀 자료실의 기술 자료를 FabGuard의 별도 PV 데이터 경로와 대조했다. 워홀 구직·비자·급여·개인 이력은 제품 요구사항이나 성능 증거로 사용하지 않는다. 기존 [SDT 계약](SDT_PV_CONTRACT.md)의 공개 시계열 결과는 데이터 품질·연동 증거이며, 실제 태양광 설비의 고장 판정이나 안전 진단 결과가 아니다.

원자료는 개인 Drive에 보존한다. 공개 저장소에는 교재·PDF 원문, 개인 이력, 현장 사진을 복제하지 않는다. Queensland 문서의 원본 이용 조건과 개정 여부는 실제 사용 시 원 제공처에서 재확인한다.

## O&M 현장 인계에 필요한 최소 기록 (설계)

| 묶음 | 공급자에게 확인할 값 | 없거나 불명확하면 |
| --- | --- | --- |
| 데이터 출처 | 공급자·접근권한·원본 버전/해시·관측/추정/기준 역할·수집 시각 | 품질 보고만 유지; 현장 사건으로 승격하지 않음 |
| 시계열 | 설비 ID와 계층(plant/inverter/string), 시간대·측정/수신 시각·간격, 전력/에너지 단위, 결측·중복·지연·보정 이력 | 비교·우선순위 계산 보류, 누락 사유 기록 |
| 운전 맥락 | 기상/일사량의 출처, curtailment·정지·시운전·정비 창, 계통/통신 상태와 각 이벤트의 유효 시각 | 저출력을 고장으로 명명하지 않고 `context_unknown`으로 분리 |
| 업무 인계 | 의심 신호 ID·근거 시계열과 원본 링크, 자산 위치, 담당자·검토 시각, 권한 있는 현장 인력의 확인/반려, work order/NCR 참조 | `unreviewed` 상태 유지; 조치·수리 완료 표시 금지 |
| 안전·접근 | 사업장별 절차·담당자·비상 연락·설비 접근 권한, 민감자료의 저장·공유 범위 | 현장 지시·전기작업 제안 없이 승인된 담당자에게 문의 |

이는 향후 데이터 공급자와 합의할 **필드 후보**다. 현행 FabGuard CLI/웹이 위 모든 필드를 수집하거나 work order를 발행한다는 뜻이 아니다. 실제 데이터의 자산 식별자, 이벤트 라벨, 담당자 승인, 권리 및 보존 기간을 확인한 뒤 별도 계약·테스트를 작성해야 한다.

## 그림자 모드 검토 시나리오

1. 원본 역할과 권리, 해시, 시간·단위·자산 ID를 확인한다. 실패 시 근거 없는 현장 알림을 만들지 않는다.
2. SDT 품질 점수와 결측·정합성을 읽되, 이를 고장 확률이나 안전 판정으로 바꾸지 않는다.
3. 저출력 구간은 일사량·curtailment·정비·통신과 대조할 후보로만 둔다. 맥락이 없으면 미확인으로 기록한다.
4. 공급자 승인 절차에서 권한 있는 담당자가 원본·업무기록을 확인하고 후속 점검 여부를 결정한다. 전기 점검·격리·재가동은 자격과 현장 절차에 따른다.
5. 기록 가능한 검증 지표는 데이터 가용률·맥락 미확인 비율·인계부터 검토까지의 시간·검토 반려율이다. 실제 사업장 데이터와 비교 기간이 없으므로 개선 수치나 사고 예방을 주장하지 않는다.

호주 워홀 자료실에서 본 구직공고, 후기, 비자·급여·자격 정보는 이 계약에 전이하지 않았다. DKASC 공개 관측 자료의 품질 실행도 특정 사업장의 SCADA·작업지시·현장 검토를 대신하지 않는다.
