# FabGuard AI 화면 명세

V1 핵심은 분석 산출물이며 화면은 시간이 남을 때 붙인다. 화면을 구현한다면 아래 3개만 만든다.

## 사용자 플로우

1. 공정 엔지니어가 전체 성능과 점검 자원별 Fail 포착 수준을 확인하려고 `평가 요약 → 위험 생산 건 목록`으로 이동한다.
2. 공정 엔지니어가 먼저 점검할 생산 건을 고르려고 `위험 생산 건 목록 → 생산 건 상세`로 이동한다.
3. 포트폴리오 평가자가 결과의 신뢰 범위를 확인하려고 `평가 요약 → 실험·한계`를 펼쳐본다.

| 화면 | 사용자가 하는 일 | 데이터 산출물 | 빈 상태 | 에러 상태 |
|---|---|---|---|---|
| 평가 요약 | 모델·지표·Top-K Capture를 확인 | metrics, CV summary | 아직 최종 평가 전임을 안내 | 결과 파일과 재실행 명령 안내 |
| 위험 생산 건 목록 | 위험도 순으로 생산 건을 정렬·선택 | priority table | 조건에 맞는 건이 없음을 안내 | 표 생성 실패와 재실행 안내 |
| 생산 건 상세 | 위험도·예측·라벨·우선 확인 변수를 확인 | priority row, explanations | 선택된 건이 없음을 안내 | 해당 ID 미존재를 안내 |

## 상태

모든 화면은 정상·로딩·빈 상태·에러 상태를 가진다. UI를 만들지 못한 경우에도 동일 네 상태를 CLI 메시지와 결과 파일 검증으로 처리한다.

## 하지 않을 화면

로그인, 실시간 모니터링, 장비 제어, 알림센터, 관리자, 원인 자동진단, LLM 챗봇은 만들지 않는다.
