# Dataset Card - UCI SECOM

## 사용 목적

SECOM의 익명화된 반도체 제조 측정값을 사용해 Fail 위험 생산 건의 우선점검 순위를 실험합니다. 실제 공정 제어, 원인 규명, 수율 개선을 위한 운영 데이터로 간주하지 않습니다.

## 원본

- Source: UCI Machine Learning Repository, SECOM
- Files: `secom.data`, `secom_labels.data`, `secom.names`
- 분석 행렬: 1,567개 생산 건 × 590개 측정변수
- Label: Pass `-1` 1,463건, Fail `1` 104건
- Period: 2008-07-19 11:55 ~ 2008-10-17 06:07

UCI 설명의 591 attributes 표기와 실제 `secom.data` 590열 사이의 차이를 임의로 해석하지 않습니다. 모델 입력은 실제 행렬에서 검증한 590개만 사용합니다.

## 데이터 품질

- 결측 셀: 41,951 / 924,530 (`4.53755%`)
- 결측 변수가 하나 이상인 열: 538
- 결측률 `>50%` 변수: 28
- non-missing 고유값 `<=1` 변수: 116
- 중복 변수 제거 후보: 104
- 완전 중복 측정행: 0

위 수치는 전체 데이터 감사용입니다. 실제 제거 열은 매 학습 폴드에서만 다시 결정합니다.

## 분할

- Train: 최초 1,175건, Fail 80건
- Temporal Test: 마지막 392건, Fail 24건
- timestamp와 sample_id는 모델 입력에서 제외
- Test는 미래 시간구간 성능과 제한된 점검 예산의 ranking을 확인하는 데 사용

## 알려진 한계

- 측정변수의 물리적 의미, 장비, 공정 단계, lot/wafer 관계가 제공되지 않습니다.
- Fail 라벨의 검사 시점과 실제 예측 의사결정 시점을 충분히 입증할 수 없습니다.
- 시간대별 라벨 비율이 변해 무작위 분할 성능을 운영 성능으로 일반화할 수 없습니다.
- 개발 스모크에서 temporal holdout이 노출돼 V1 결과는 provisional입니다.
