## 해석과 다음 단계

- 부스팅은 RF 대비 평균 AP +0.143322, 구간별 AP는 3/4회 높았다.
  그러나 Top10 포착의 RF 대비 증가 2건은 세 번째 구간에서만 발생했다.
  마지막 구간은 AP가 RF보다 낮고 불량 3건을 모두 놓쳤다.
- 기존 L1도 총 4건을 포착했다. 부스팅의 AP 증가를 추가 점검 성과로 과장하면 안 된다.
- 결측 개수는 AP 평균이 높았지만 2/4개 구간에서 RF보다 낮았다.
  결측 indicator 제거도 AP 차이가 작다. 어떤 전처리도 보편적 개선으로 확정하지 않는다.
- 시간 구간에 따라 불량률이 낮고 변동이 크다. 평균 AP 순위는 탐색 후보를 고르는 근거만 제공한다.
  유의성 검정·신뢰구간·독립 검증을 수행하지 않았고, 과거 Test 노출도 소급해 없애지 못한다.
- 기존 모델은 유지한다. 후속으로 더 넓은 사전 고정 train-only 검증을 설계하고,
  가능하면 새로운 시기/동일 공정의 독립 데이터에서 후보를 검증한다.

## 재현

저장소 루트에서 공식 UCI 원본 3파일을 `data/raw`에 준비하고 사전 계약의 명령을 실행한다.
원본은 loader가 공식 SHA-256으로 검증한다. 신규 외부 의존성은 없다.
재실행하면 manifest의 git revision은 해당 실행 커밋으로 갱신된다.
입력 파일 파싱/무결성 확인 외에는 Test를 사용하지 않는다.
