# 현장 인과효과 검증 계획

FabGuard V1은 공개 SECOM 데이터에서 수행한 오프라인 위험순위화 실험이다. 이 문서는 향후 실제 제조 현장에 연결했을 때 **FabGuard 때문에 운영 결과가 달라졌는지** 검증하기 위한 제안 계획이며, 완료된 현장 실험이나 현재 성과의 증거가 아니다.

## 검증 질문과 분석 단위

검증 전에 처리(treatment), 비교조건, 분석 단위와 관찰기간을 고정한다.

- **처리**: 엔지니어가 FabGuard Top-K 점검 큐를 제공받는 운영 방식
- **비교조건**: 기존 점검 절차 또는 FabGuard 점수를 노출하지 않은 운영 방식
- **분석 단위 후보**: Lot·wafer·tool·chamber·shift·생산라인 중 현장 간섭이 가장 적은 단위
- **주요 질문**: 동일한 점검자원에서 확인된 Fail 포착과 의사결정시간이 개선되는가
- **안전 경계**: 모델은 점검 순서만 제안하며 보류·재검사·설비조치는 엔지니어가 승인한다

## 우선 측정 지표

| 수준 | 지표 후보 | 해석 |
|---|---|---|
| 운영 | 큐 확인률, 점검 완료시간, 추가 점검 건수, 경보 부담 | 실제 작업기록에서 직접 측정 |
| 품질 | 점검된 건의 Fail 포착, 누락 Fail, 재검사·보류 결과 | 라벨 정의와 판정시점을 사전에 고정 |
| 제조 | 불량률, 리드타임, 가동률 | 공정·기간·동시개입을 통제한 현장 검증 필요 |
| 사업 | 수율, 제조원가, 비용절감 | V1에서 주장하지 않으며 별도 장기 검증 필요 |

## 권장 평가 설계

### 1. 무작위 또는 단계적 현장시험

운영상 가능하면 shift·라인·기간 블록을 무작위로 배정해 FabGuard 제공군과 기존 절차군을 비교한다. 작업자가 두 절차를 동시에 접해 생기는 오염을 줄이기 위해 개별 생산 건보다 cluster 단위 배정을 우선 검토한다. 전면 도입이 예정돼 있다면 도입 순서를 무작위화하는 단계적 도입(stepped rollout)도 사용할 수 있다.

### 2. 자연실험과 이중차분

무작위 배정이 불가능하면 도입 라인과 유사한 미도입 라인의 **도입 전후 변화 차이**를 비교한다. 단순한 도입 전후 수치 변화만으로 FabGuard의 인과효과를 주장하지 않는다.

이중차분을 사용할 때는 다음을 함께 확인한다.

- 도입 전 처리군과 비교군의 추세가 유사했는지 시각화하고 기간별 추정치를 점검한다.
- recipe·설비·검사기준·인력·교육 등 결과에 영향을 줄 동시 변경을 기록한다.
- 처리군과 비교군의 구성, 측정방식과 라벨 정의가 기간 중 안정적이었는지 확인한다.
- 다른 라인이나 shift로 점검 방식이 전파되는 spillover와 선택적 도입 가능성을 조사한다.
- 평행추세 점검은 가정을 보장하는 증명이 아니라 설계 타당성을 판단하는 진단으로 사용한다.

### 3. 컷오프 기반 불연속회귀

현장에서 고정된 위험점수 또는 Top-K 경계가 점검 여부를 실제로 결정한다면, 경계 바로 위와 아래의 생산 건을 비교하는 불연속회귀를 후보로 검토할 수 있다. 이 설계는 전체 생산 건에 대한 평균효과가 아니라 **컷오프 주변의 국소 효과**를 추정한다.

다음 조건이 충족되지 않으면 사용하지 않는다.

- 점검 여부를 결정하는 사전 고정 cutoff와 assignment rule이 존재한다.
- 작업자가 점수나 순위를 임의로 조작해 경계의 어느 쪽에 배치될 수 없다.
- cutoff 부근에서 점검 여부 외의 공정·설비·인력 조건이 연속적이다.
- cutoff 양쪽의 표본 수, 대역폭 선택과 다른 임계값·운영규칙의 개입을 공개한다.
- 점검예산이 매번 달라지는 일반 Top-K 운영은 그 자체만으로 불연속회귀 조건을 충족하지 않는다.

## 현장 데이터 계약

최소한 다음 항목을 같은 감사 로그에서 연결해야 한다.

- Lot·wafer·tool·chamber·recipe·공정 단계와 event timestamp
- 모델 버전, 위험점수, Top-K 예산과 실제 노출 여부
- 큐 확인시간, 엔지니어 판단, 재검사·보류·설비점검 조치
- 최종 품질 결과, 라벨 확정시점과 사후 수정 이력
- shift·인력·설비·검사기준 등 주요 운영 변경

## 선택적 라벨과 인간 판단 감사

현장에서는 정밀검사·재검사 대상으로 선택된 생산 건에만 최종 품질 라벨이 빠르게 확정될 수 있다. 이때 관측된 결과만으로 모델이나 엔지니어 판단을 비교하면, 원래 점검되지 않은 생산 건의 결과가 빠져 성능을 과대·과소평가할 수 있다.

- 모델 추천 여부, 실제 점검 여부와 최종 라벨 관측 여부를 서로 다른 필드로 기록한다.
- 무작위 표본감사 또는 기존 품질검사 결과를 이용해 미점검군의 결과 누락 정도를 추정한다.
- 엔지니어가 모델 순위를 변경했다면 사유·시간·후속 결과를 기록하되, 인간 판단을 곧바로 정답 라벨로 사용하지 않는다.
- 모델 단독, 기존 절차, 인간 검토 결합 방식의 성능과 점검부담을 같은 조건에서 비교한다.
- tool·line·shift 등 운영 하위집단별 오류율과 점검부담을 확인한다. 보호속성이나 충분한 표본이 없는 V1에서는 사회적 공정성을 검증했다고 주장하지 않는다.

## 분석·보고 원칙

- 주요 지표, 분석기간, 제외기준과 표본크기 판단을 결과 확인 전에 고정한다.
- 배정된 운영방식을 기준으로 분석하고, 실제 큐 확인 여부를 별도 보조분석으로 구분한다.
- 점추정치만이 아니라 불확실성 구간과 표본 수를 함께 보고한다.
- 하위 공정·설비 분석은 탐색적 결과로 표시하고 다중 비교 위험을 기록한다.
- 데이터 누락, 라벨 지연, 모델 변경과 분포 이동이 크면 효과 추정을 중단하거나 재설계한다.

## 주장 경계

현재 말할 수 있는 것은 고정 공개데이터에서 측정한 PR-AUC, Top-K 포착률, lift와 점검 건수다. 현장시험 전에는 다음 문구를 사용하지 않는다.

- “FabGuard가 수율을 개선했다.”
- “FabGuard 때문에 불량률이나 비용이 감소했다.”
- “중요 익명변수가 실제 공정 원인이다.”

현장 도입 후에도 연구설계가 뒷받침하는 수준에서만 연관 또는 인과효과를 구분해 보고한다.

## 방법론 참고 범위

2026년 9월 법원 특강에서 다룬 반사실, 무작위 통제실험, 자연실험, 이중차분과 불연속회귀의 일반 원리를 현장검증 계획에 참고했다. 강의 사진·슬라이드·도표·표현·사례 수치는 저장소나 웹에 복제하지 않았으며, FabGuard의 학습 데이터나 성능 근거로 사용하지 않았다. 이 문서는 방법론을 FabGuard의 고유한 운영조건에 맞게 재구성한 것이다. 전체 강의기록과 공개 가능한 서지정보를 확인한 뒤 정확한 강의명·강사·출처 표기만 별도로 보완한다.
