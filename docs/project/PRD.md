# PRD - FabGuard AI V1

## 한 문장

공정 엔지니어가 제한된 점검 시간 안에 어떤 생산 건부터 확인해야 할지 판단하기 어려울 때, SECOM 측정 데이터로 Fail 위험순위와 우선 확인 변수를 제공해 점검 우선순위 결정을 돕는다.

## 사용자

1차 사용자는 반도체 제조 공정의 이상 생산 건을 선별하는 공정·수율 엔지니어다. Day 7에는 반도체 현업 경험자에게 사용자 가정과 화면 흐름을 확인받고, 확인 전까지는 이를 검증되지 않은 사용자 가정으로 표시한다.

## 현재 대체재

엔지니어가 다수 측정변수, 관리 기준, 장비·공정 이력과 경험을 바탕으로 생산 건을 수동 선별한다고 가정한다. 공개 데이터에는 현업의 실제 점검 절차가 없으므로, 이 대체재 설명은 Day 7 인터뷰 전까지 가정이다.

## 2주 쐐기

보존된 테스트 생산 건을 위험순으로 정렬하고, 각 건에 예측 위험도와 모델이 우선 확인 대상으로 제시한 익명 측정변수를 함께 보여주는 한 흐름을 완성한다.

## 성공 판정

Day 14 데모에서 사용자가 3분 안에 전체 모델 평가를 확인하고, 위험 생산 건 목록에서 한 건을 선택해 위험도·예측·실제 라벨·우선 확인 변수·주의 문구를 볼 수 있다.

## 안 만들 것

- 실제 불량 원인 규명 또는 인과관계 주장
- 센서·공정 변수의 물리적 의미 추정
- 실시간 설비 연동, FDC/APC/SPC 구축
- 딥러닝, LLM, RAG, 에이전트 프레임워크
- 로그인, 사용자 관리, 결제, 알림
- 대규모 대시보드와 복잡한 프론트엔드
- 테스트 세트 반복 확인을 통한 모델 튜닝
- 검증되지 않은 비용절감·수율개선 수치

## 암묵지

1. Fail은 희소하므로 Accuracy만으로 모델을 선택하지 않는다.
2. 테스트 세트는 최종 1회 평가 전까지 잠그고, 모든 전처리는 학습 폴드 내부에서 적합한다.
3. 익명 변수의 중요도는 점검 후보 근거일 뿐 실제 원인이나 조치 지시가 아니다.

## 가장 큰 불확실성

공개 SECOM의 익명 측정변수와 제한된 맥락만으로 만든 priority table이 현업 엔지니어에게 실제로 유용한지 여부다.
