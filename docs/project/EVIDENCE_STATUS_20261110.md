# FabGuard 공개 근거와 평가 상태 — 2026-11-10

이 문서는 기존 공개 결과와 별도 자료의 평가 경계를 정리합니다. 새 학습·추론·재채점 결과를 추가하지 않으며 기존 모델·점수·대표 수치를 바꾸지 않습니다.

## SECOM 본체

공개 V1은 후기 392건·Fail 24건 가운데 상위 40건을 점검해 5건을 포착했습니다. 포착률은 5/24(20.8%), 점검 정밀도는 5/40(12.5%)입니다. AP는 약 0.0935이며, 임계값 0.5에서는 TP=0입니다. 홀드아웃 노출 이력이 있는 잠정 결과로서 독립 제조 현장 성능을 뜻하지 않습니다.

개발자료에서 비교한 성적과 V1 후기 평가를 합치지 않습니다. 합성 검사 통과, 저장 결과 대조, 웹 기능 개선은 새 예측 성능의 증거가 아닙니다.

## 다른 자료와의 경계

| 범위 | 공개 시 해석 |
|---|---|
| 공개 로봇 벤치마크·UR3 기록 | SECOM과 다른 과제입니다. [기존 로봇 벤치마크](../ROBOT_IMAD_BENCHMARK.md)와 기록 재생을 실제 공장 연결·미래 고장 예측으로 해석하지 않습니다. |
| voraus-AD 로봇·유압 설비 상태진단 | 각각 별도 보조 연구 범위입니다. 출처·입력·라벨·점검 예산과 평가 조건이 다르므로 결과를 SECOM 성능으로 합산하지 않습니다. |
| SDU UR5e | 인수·구조 확인과 모델 평가는 다릅니다. 실제 평가는 보류 상태이며, 정상 자료 대응·세션/반복 관계·입력 및 라벨 시점 근거가 필요합니다. 승인은 누락된 근거를 대신하지 않습니다. |
| 합성 SMT/OHT·점검 메모·인계 | 설명·검토를 돕는 기능입니다. 원인 확정, 작업 승인, 실제 장비 제어·안전 인증을 뜻하지 않습니다. |

개별 보조 실험의 미공개 결과나 원자료는 이 문서에 포함하지 않습니다. 서로 다른 데이터의 점수, 초기 실패와 후속 성공, 합성 검사와 실제 데이터 실행을 하나의 성능 수치나 검사 수로 합산하지 않습니다.

## 기록과 기여

확인한 코드·입력 버전, 실행 횟수, 성공/실패/미실행, 노출 이력과 주장 한계를 구분해 보존합니다. 전체 Git 이력이 복원됐거나 모든 작업이 운영 배포됐다고 주장하지 않습니다.

사용자는 문제·범위·승인과 직접 수행한 재현을 결정하며, Codex의 구현·정리와 다른 검토자의 검토 범위는 [AI 활용 기록](../governance/AI_USAGE.md)·[기여 기록](../governance/CONTRIBUTIONS.md)으로 구분합니다. AI 작성 코드를 사용자가 모두 직접 작성했다고 표현하지 않습니다.

현재 근거로 실제 반도체 수율 개선·현장 비용 절감·독립 LOT/미래 생산 일반화를 주장하지 않습니다. 이 문서 변경 자체는 웹 배포나 새 모델 승격이 아닙니다.
