# 선택형 저장 점수 진단

`fabguard.score_diagnostics.diagnose_score_windows([raw_json_bytes, ...])`는 기존 `fabguard-capture-input/v1` 입력을 받아 상수점수, 검사예산 K 경계의 동점, 알려진 불량의 미포착을 경고한다. 기존 `capture_transitions._load`의 제한·중복키 거부·정확한 Decimal 정렬·ID 동점 계약을 재사용하며 학습·추론·파일 읽기/쓰기·네트워크·모델 선택·운영 승인을 하지 않는다. 기존 비교기 반환값은 바꾸지 않는다. private parser에 의존하므로 그 계약 변경 시 관련 테스트를 함께 실행한다.

## 기존 기능과의 차이
- main의 capture transitions는 두 제출점수의 선택 변화만 비교한다. 이 진단은 각 제출 점수창에서 **구분 신호 없는 상수점수, K 경계 동점 의존, 시기별 미포착**을 따로 표시한다.
- Draft #140 KAMP 연구에는 이미 일별 포착, 200회 무작위 동점 민감도, 점수 포화·분포 진단이 있다. 개념이 새롭다는 주장은 하지 않는다. 해당 코드는 KAMP 전처리·학습·연구 산출물에 묶인 실험 스크립트다. 새 코드는 그 스크립트나 결과를 가져오지 않고 현재 공유 입력계약을 사용하며, K 경계의 알려진 불량 포착 가능한 최소/최대를 조합식으로 정확히 계산한다. 몬테카를로 반복, 새 의존성, 상관·왜도 기능, 재학습은 추가하지 않는다.
- #230 시간분리·walk-forward 수정이나 #231 리뷰 접수 진단을 대체하지 않는다. train/test 분리가 실제 지켜졌는지 이 API가 증명하지 않는다.

## 입력과 해석
- 1~100개의 bytes 입력, 합계 최대8 MB. 각각 기존 capture v1 schema를 따른다. 같은 선언 dataset hash와 label rule이어야 하며 창 간 ID 중복, 역순·겹치는 시각·같은 경계시각을 거부한다.
- 각 창의 K와 모델 버전은 호출자가 정한다. 일일 예산을 자동 추정하지 않고 전체 기간의 합산 성능이나 우승 모델을 계산하지 않는다. 창/K 선택의 적절성·사전 고정·실제 날짜는 인증하지 않는다.
- 점수가 모두 같으면 해당 창 내부에 **점수 순위 구분 신호가 없다**고 알린다. 모델이 어느 데이터에서도 무효라는 뜻은 아니다. 서로 다른 점수도 실제 유용한 신호를 보장하지 않는다.
- K 경계 동점집합의 일부만 선택될 때 ID순서가 선택에 영향을 준다. 실제 ID순 선택 포착값과 가능한 최소/최대를 분리하며, 최댓값으로 실제 포착값을 대체하지 않는다. 이 범위는 오직 알려진 Fail 라벨의 조합 범위이며 신뢰구간·랜덤 기대값·재현 성능이 아니다.
- `NO_KNOWN_FAIL_DENOMINATOR`는 성공이 아니다. `ZERO_KNOWN_FAIL_CAPTURE`는 알려진 Fail이 존재하나 선택되지 않았다는 뜻이다. unknown 라벨 수와 선택된 unknown을 별도 표시하고 unknown을 정상/불량으로 바꾸지 않는다. unknown이 있으면 실제 포착 성능은 불완전하다.
- 반환 상태는 `DESCRIPTIVE_WARNINGS_ONLY`, `WITHHELD`, `independent_evaluation=false`이다. 실제 제조 효과·독립 검증·원자료 진위·라벨 시점·사전 고정 정책을 증명하지 않는다.
- 원본 개별 ID/라벨/점수를 출력하지 않지만 해시·시각·집계는 포함한다. 익명화나 공유 안전 보증이 아니므로 전달 전 검토한다.

## 합성 예시
3개 점수가 전부0.5이고 ID순 라벨이 [0,1,0], K=1이면 실제 알려진 불량 포착은0이다. 상수점수 및 경계 동점 경고와 가능한 알려진 불량 포착범위0~1을 함께 반환한다. 이를 1건 포착으로 보고하지 않는다.

## 검증
`PYTHONPATH=src python -m unittest discover -s tests -p test_score_diagnostics.py -v`
기존 parser 회귀검사도 함께 실행한다. 모델·홀드아웃·기존 실험 결과·웹/배포는 변경하지 않는다. 외부 리뷰와 전체 CI는 별도 단계다.
