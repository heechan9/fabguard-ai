# 화면·주요 동작 점검 — 2026-09-24

점검 기준: main `7dd6acf52e05f2e06ee4d3cd8b6aad5593988527`, 배포 사이트 https://fabguard-ai.vercel.app/ .
Cloud Chrome의 데스크톱 화면에서 직접 탐색했다. 전체 조합·모든 브라우저 통과를 의미하지 않는다.

## 발견 및 수정

1. 국가별 화면이 RTE 연간 검증을 재실행/연결 대기로 표시했다. 기존 정본의 보고서와 366일 수집 감사를 공통 snapshot에 추가하고, RTE 선택 카드와 한국어/영어 상태 문구를 갱신했다. 17,568개 간격, 결측 전력 2개, consolidated 2개, 수집 및 SDT 품질 경고를 보존한다. 원본 데이터를 재분석한 작업은 아니다.
2. 홈의 ‘본문으로 건너뛰기’를 키보드 Enter로 실행하면 `#app`을 화면 경로로 해석하여 ‘화면을 찾을 수 없습니다’가 표시됐다. 현재 경로를 유지하고 본문으로 포커스와 스크롤을 옮기도록 수정했다. 실제 app 초기화 코드를 실행하는 회귀검사를 추가했다.

## 검증과 남은 범위

- `python scripts/build_web_evidence.py --check`: 정본 파일의 Git blob hash와 생성 snapshot 일치.
- 관련 Node 테스트와 JavaScript 문법 검사 통과. 전체 테스트는 PR CI에서 검증한다.
- 로컬 전체 Node 테스트 첫 시도는 부분 체크아웃에 없는 vendor/예제/Python 파일 때문에 실패했다. 해당 실패를 제품 회귀나 통과로 계산하지 않는다.
- 현재 브라우저 API에는 viewport 변경 기능이 없어 모바일 크기의 실제 렌더링·터치·회전은 미검증이다. 반응형 CSS 존재 확인만으로 모바일 통과를 주장하지 않는다.
- 이 브라우저는 WebGL을 생성하지 못했다. 실제 3D 렌더링·녹화 파일·기기별 코덱은 이번 점검에서 재검증하지 않았다. 사용자가 앞서 확인한 PC 녹화와 별도다.
- 네트워크 차단에 의한 자료 로딩 실패/복구 주입, 전체 언어 번역, 모든 키보드 동작·명암비에 대한 접근성 감사는 미실시다.
- 외부 전문가의 방법론 평가·독립 제조 데이터 성능 검증은 별도이며 완료로 표시하지 않는다.
