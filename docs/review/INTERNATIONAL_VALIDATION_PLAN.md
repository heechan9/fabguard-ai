# FabGuard 국제 검증 협력 계획

**상태 (2026-10-23): 협력 목표·접촉 후보.** 아래 기관과 접촉하거나 협약·데이터 접근·현장 시험을 승인받았다는 기록이 아니다. 기관별 연구 주제와 참여 경로는 연락 전에 다시 확인한다.

## 하나의 검증 질문

새 운전 조건이나 품질이 낮은 센서 입력을 받았을 때, FabGuard가 언제 오프라인 우선점검 결과만 제시하고 언제 판단을 보류해야 하는가? 사람의 확인 및 오경보·미탐 부담을 함께 측정한다. 반도체 생산 건, 로봇 구간, 태양광 시계열은 서로 다른 데이터 계약과 성능 지표를 유지하며 결과를 합산하지 않는다.

현재 [SECOM 정본](../../results/v1/RESULTS_SUMMARY.md)은 공개 데이터의 노출 이력이 있는 후기 홀드아웃에서 AP 0.0935, 상위 40건의 Fail 5/24 포착이다. [IMAD-DS 로봇 실험](../ROBOT_IMAD_BENCHMARK.md)은 축소 실험실 로봇의 의도적 나사 풀림 한 종류이며, 세션 분리 target AUROC 0.4793, 상위 24구간의 이상 1/116 포착이다. 둘 다 현장 성능의 근거가 아니다. 로봇 입력 품질·판단 보류는 [Draft #164](https://github.com/heechan9/fabguard-ai/pull/164)의 **구현 전 설계**로만 다룬다.

## 지역별 역할과 첫 요청

| 단계 | 접촉 후보 (공식 안내) | 제안할 작은 범위 | 완료로 셀 증거 |
|---|---|---|---|
| 호주, 1차 | [Swinburne Factory of the Future](https://www.swinburne.edu.au/research/platforms-initiatives/factory-of-the-future/) 또는 [RMIT Advanced Manufacturing Precinct](https://www.rmit.edu.au/about/our-locations-and-facilities/facilities/research-facilities/advanced-manufacturing-precinct) | 연구질문·센서/운전조건 정의를 검토하고, 동의된 새 녹화나 현장 자료로 제한된 그림자 평가의 가능성을 논의 | 연구자 답신과 검토 기록; 실제 파일럿은 별도 허가·프로토콜·신규 데이터가 있을 때만 기록 |
| 북미, 2차 | [CESMII Smart Manufacturing Institute](https://www.cesmii.org/about/) 및 주제에 맞는 참여 연구팀 | 호주에서 작성한 데이터 계약, 점검 부담, 미탐·오경보 지표를 독립 검토 요청 | 범위가 적힌 서면 피드백 또는 독립 재현 기록 |
| 유럽, 3차 | [Fraunhofer Group for Production의 AI 분야](https://www.produktion.fraunhofer.de/en/research/futuretopics/AI_in_Manufacturing/ai-applcations-in-the-group-for-production.html) 중 관련 팀 | 조건 변화·센서 이상·판단 보류 방법론과 새로운 검증 조건에 대한 기술 의견 요청 | 검토 범위와 반례·수정 권고가 남은 기록 |

후보 기관은 연구 분야의 적합성을 보고 고른 **접촉 출발점**이다. 개인 프로젝트에 대한 무상 협력, 장비·데이터 제공, 회원 자격 또는 연구비 지원을 뜻하지 않는다. 세 지역의 정식 협약 3건을 당장의 성공 기준으로 삼지 않는다. 첫 단계 목표는 호주에서 실험 가능성을 구체화하고 북미·유럽에서 범위가 명시된 기술 검토를 받는 것이다.

## 순서와 진행 조건

1. **연락 전:** [기존 영문 소개](../MELBOURNE_COLLABORATION.md)를 최신 로봇 부정 결과와 이 계획에 맞춰 갱신한다. 1쪽 소개에는 질문 하나, 기존 실패 수치, 원하는 검토 범위, 재현 링크, 요청 시간, 공개 가능 범위를 담고, 별도의 2쪽 평가 계약 요약을 기술 검토 대상으로 준비한다. 최희찬의 실제 기여와 AI 보조 구현을 구분한다.
2. **호주 현지 단계 (2027년 체류 계획과 연동):** 해당 기관·사업장이 자료 접근, 연구 사용, 보관과 결과 공개를 허용하는 범위를 문서로 정한다. 기존 시험 구간은 튜닝에 재사용하지 않는다. 새 세션/운전조건의 분할 원칙을 먼저 정하고, 훈련·개발 자료에서 선택한 모델·평가·보류 규칙을 **최종 시험 라벨·결과 접근 전에** 고정한다. 개발용 라벨과 최종 시험 라벨의 접근 권한을 분리하고 독립 자료 관리자가 시험 라벨을 보관한다. 현장 업무나 태양광 관측 자료를 확보해도 제조·로봇 성능으로 전환해 주장하지 않는다.
3. **북미·유럽 단계:** 호주에서 실제로 수행된 범위와 실패를 포함한 결과를 공유하고, 각각 한 가지 질문에 대한 독립 검토를 요청한다. 회신·재현·공동 파일럿·정식 협약은 상태를 나눠 기록한다.

새 녹화의 조건 범위, 기준선 대비 AP/AUROC와 점검 상위 구간의 포착·오경보, 결측/시간 불일치 보류율, 사람 검토 부담을 사전에 정한 분할에서 보고한다. 표본 수나 라벨이 부족하면 지표의 불확실성·계산 불가 사유를 남긴다. 로봇의 물리 센서 동기화와 새로운 조건의 커버리지가 확인되기 전에는 온라인 경보·자동 정지·제어를 제안하지 않는다.

## 검증 실행 전 완료할 계약

[로봇 잠금 평가 계약](ROBOT_LOCKED_EVALUATION_CONTRACT.md)은 아직 미승인·미실행 템플릿이다. 기관·장비·설치·녹화 세션 단위의 실제 독립성, 훈련/개발/시험 그룹 목록, 시험 라벨 관리자, 모델·입력·프로토콜 해시를 고정해야 한다. 기존 IMAD 원본 재실행은 재현 확인이며 신규 독립 데이터가 아니다.

판단 보류 사례를 분모에서 지워 성능이 좋아졌다고 보고하지 않는다. 전체 모집단의 무효/입력 품질 보류/조건 보류/순위 허용 수, 각 상태의 이상 수와 라벨 미확인 수, 허용된 부분집합 지표, 전체 이상 중 실제 포착 비율, 보류 건을 포함한 사람 검토 부담을 구분한다. 그룹 단위 불확실성과 사전에 고른 단순 기준선을 함께 보고한다. 표본·라벨·물리 그룹 근거가 부족하면 실행 가능성 조사로만 남긴다.

첫 기관 요청은 이 계약을 요약한 2쪽 문서에서 세션 분리·센서 품질·보류 처리 중 가장 중요한 결함 하나에 대한 서면 기술 의견이다. 검토 범위·예상 노력·이름 인용 여부를 합의하며, 데이터·장비 제공이나 파일럿 참여를 전제하지 않는다. 계약의 요청 문안은 미발송 초안이다.

**공개 상태:** 협력 요청 미발송, 외부 기관 회신 없음, 새 현장 데이터 없음, 3개 지역 공동 프로젝트 미성립. 실제 진전이 생길 때만 날짜·기관·확인 범위·공개 허락·근거 링크를 추가한다.
