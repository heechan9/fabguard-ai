## Human notes and preservation

No note means pending. A person explicitly appends a revision with a self-declared/unverified role,
UTC review time, outcome, proposed action, rationale, available evidence and missing evidence.
Default insufficient_evidence/hold cannot become release, approval, restart or a causal verdict.
`documented_observation` records a note, not quality clearance.

History is in page memory only. Download JSON to retain it; reload/navigation may lose unsaved data.
Language and theme changes in this page preserve notes. No server upload, login, automatic model update,
physical control, database or identity verification is added. Imported history is editable and unsigned;
source hashes establish source-content matching, not reviewer authenticity or a tamper-proof journal.

Schema `fabguard-secom-offline-review/v1` contains exactly `schema_version`, `source`, `history`.
At most 100 revisions, 1 MiB input and canonical exported UTF-8 bytes (including formatting/newline),
12 nested levels; malformed UTF-8, directional formatting controls, unknown/duplicate fields, nonfinite numbers, wrong source,
unknown IDs, modified saved values and noncontiguous revisions fail closed. Review and recorded times are
canonical UTC ISO with milliseconds; reviewer time cannot exceed record time or current clock, both must
be nondecreasing. Review time cannot predate this pinned evidence version's commit time
2026-10-31T03:12:35.000Z. That lower bound is not the 2008 measurement time.

An import must preserve the complete existing local history as a matching prefix; older or divergent
exports cannot silently truncate/replace local notes. Entire input validates before replacement. Failure
leaves current notes and form untouched. This guards ordinary accidental replacement, not hostile editing
of a fresh browser session or a compromised host. JSON text is rendered as text, not executable markup.
