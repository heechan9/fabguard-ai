# 외부 데이터 자격 심사

상태: **입력 게이트 · 데이터별 실행 필요**

외부 데이터가 저장소에 존재하거나 파이프라인을 통과했다는 사실과, SECOM 모델을 평가할
자격이 있다는 판단은 다르다. 이 문서는 `관측(observed)`, `추정(estimated)`, `기준(reference)`,
`합성(synthetic)` 자료를 시각적으로도 구분하는 웹 원칙과 동일한 의미 경계를 사용한다.

## 1. 네 가지 데이터 유형

| 유형 | 의미 | 허용되는 증거 | 금지되는 확대 해석 |
|---|---|---|---|
| Observed | 장비·관측소 등에서 직접 측정된 값 | 수집·정규화·품질·계보 검증 | 곧바로 SECOM 외부검증으로 간주 |
| Estimated | 여러 입력과 방법으로 추정한 값 | 추정자료 계약과 재현성 검증 | 직접 센서 측정값으로 표현 |
| Reference | 모델·가정으로 만든 비교 기준값 | 기준 파이프라인 호환성 | 현장 관측 또는 정답 라벨로 표현 |
| Synthetic | 코드로 생성한 시험 입력 | 오류경로·인터페이스·시뮬레이션 검증 | 실제 생산·현장 성능 증거로 표현 |

## 2. 공통 필수 게이트

- **출처:** 공식 제공자, 데이터셋 버전, 조회시각과 영구 식별자를 기록한다.
- **권리:** 라이선스, 연구·상업 이용, 재배포 및 개인정보·영업비밀 제한을 확인한다.
- **무결성:** 원본과 정규화 파일의 SHA-256, 행 수, 변환 코드를 기록한다.
- **스키마:** 열 의미, 단위, 시간대, 표본 주기, 결측·중복·수정 정책을 명시한다.
- **대표성:** 설비·공정·기간·제품·지역 범위와 제외 대상을 기록한다.
- **독립성:** V1 개발·선정에 쓰이지 않았고 중복 생산 건이나 파생본이 아님을 확인한다.
- **라벨:** 생성 시점, 판정자, 검사법, 지연·재작업·선택적 관측 여부를 확인한다.
- **누출:** 동일 Lot·기판·시간창·복제 이미지가 분할 경계를 넘지 않게 한다.

필수 항목 하나라도 불명확하면 `candidate` 또는 `blocked`다. 누락을 추정으로 메워 `qualified`로
승격하지 않는다.

## 3. 목적별 추가 게이트

### SECOM 잠금 모델 외부평가

590개 익명 특징 이름이 같다는 것만으로 부족하다. 변수의 물리적 의미·단위·측정 시점,
Fail 정의와 공정 모집단의 호환성이 전문가 검토를 통과해야 한다. 그렇지 않으면 스키마 검사만
수행하고 성능값을 만들지 않는다.

### NVIDIA TAO AOI 후보

실제 AOI 이미지, 결함 라벨, golden 기준 이미지와 기판·Lot 단위 분할이 필요하다. 현재 SMT
합성 기판과 이상값은 학습자료가 아니다. 세부 조건은
[`validation/NVIDIA_TAO_AOI_EXPERIMENT_CONTRACT.md`](validation/NVIDIA_TAO_AOI_EXPERIMENT_CONTRACT.md)를
따른다.

### PV·기상·로봇 자료

수집·감사·품질 파이프라인을 검증할 수 있지만 반도체 모델 성능과 합치지 않는다. 서로 다른
연구질문, 입력 계약과 결과 디렉터리를 유지한다.

## 4. 판정 기록

각 데이터셋은 다음 상태 중 하나만 가진다.

- `candidate`: 출처 후보만 등록됨
- `preflight`: 접근·권리·스키마 조사 중
- `qualified_for_pipeline`: 해당 도메인의 수집·품질 실행 가능
- `qualified_for_locked_evaluation`: 동결 모델의 사전 승인된 1회 평가 가능
- `blocked`: 필수 근거 누락 또는 계약 위반

판정 문서에는 검토자, 날짜, 근거 경로, 미해결 위험과 허용된 주장 범위를 함께 남긴다.
