## 무엇을 하는 프로젝트인가요?

저장된 생산 기록을 보면서 사람이 무엇부터 확인할지 돕는 연구용 프로젝트입니다. 모든 화면이 하나의 AI 모델에 연결되어 있는 것은 아닙니다.

1. **SECOM 우선점검**: 이미 계산된 점수 순으로 공개 기록을 읽고 점검 범위를 선택합니다. 메모와 인계 기록은 사람의 검토 초안입니다. 새 파일 예측이나 현장 승인이 아닙니다. [화면](https://fabguard-ai.vercel.app/#risks) · [정본 결과](../results/v1/RESULTS_SUMMARY.md)
2. **장비 CSV·정비 이력 점검**: 브라우저에서 파일을 읽고 참고 관리선·변경 이력·보류 이유를 확인합니다. 원본 대조와 감사 기록에는 별도 Python 재계산이 필요합니다. 정비 전후 모델 성능 평가 기능은 아닙니다. [화면](https://fabguard-ai.vercel.app/equipment/context-review.html) · [원본·이력 계약](MAINTENANCE_CONTEXT_REVIEW.md)
3. **UR3 실제 센서 기록**: 공개된 과거 측정 기록을 탐색·재생합니다. 실시간 연결·고장 예측·로봇 제어는 하지 않습니다. [화면](https://fabguard-ai.vercel.app/robot/ur3/)
4. **SMT·OHT 합성 체험**: 가상 기판 흐름과 검사·보류, 온도 가정·가상 정지, 천장 이송을 보여 줍니다. 실제 설비 물리 해석·제어·안전 인증이나 SECOM 예측 결과가 아닙니다. [SMT](https://fabguard-ai.vercel.app/smt/) · [OHT](https://fabguard-ai.vercel.app/oht/)
5. **선택형 학습**: 합성 사례 3개로 데이터 품질과 판단 근거를 연습합니다. 실제 안전 판정이나 학습자 능력 평가가 아닙니다. [소개 화면](https://fabguard-ai.vercel.app/#summary) 하단에서 시작합니다.

## 검사 통과와 현장 성능은 어떻게 다른가요?

- 코드 검사는 정해 둔 입력에서 코드가 예상대로 동작하는지 확인합니다.
- 저장 결과 대조는 같은 자료를 다시 계산했을 때 수치가 맞는지 확인합니다.
- 실제 예측 성능은 사용 시점에 알 수 있었던 입력과 이후 확인된 결과를 분리해 평가해야 합니다.
- 정비 효과 평가는 정비·재가동 기록, 웨이퍼·LOT 연결 정보, 입력·라벨의 최초 이용 가능 시각과 비교 조건이 필요합니다.

앞의 두 가지를 통과해도 뒤의 두 가지를 입증하지 않습니다. 합성 사례, 실제 과거 기록과 서로 다른 연구 결과를 하나의 성능 수치로 합치지 않습니다. 별도 연구·검토용 코드도 이 웹에 자동으로 연결되지 않습니다.

SECOM의 잠정 결과, 홀드아웃 노출 이력, 실제 평가 보류 범위는 [공개 근거와 평가 상태](project/EVIDENCE_STATUS_20261110.md)에서 확인합니다. 미공개 연구 결과·검증기 소스·원자료·개인 링크는 이 안내에 포함하지 않습니다.
