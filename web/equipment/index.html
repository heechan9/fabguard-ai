실장비 데이터 검증

파일 선택 → 열 매핑 → 입력 검증. 파일 내용은 이 브라우저 메모리에서만 처리하며 서버로 보내거나 저장하지 않습니다.

업로드 파일은 입력 검증 전용입니다. 아래 SPC 체험은 별도 합성 예제이며, 업로드 자료나 SECOM 모델과 연결되지 않습니다. 첫 버전은 SPI 숫자 측정 CSV만 지원합니다. AOI 영상·XLSX는 지원하지 않습니다.

1. CSV 파일 선택

UTF-8, 쉼표 구분, 최대 5MB·20,000행. 파일 하나에 같은 장비·Recipe·실행의 측정 항목 한 종류만 넣으세요. 반복측정은 실행별 파일로 분리하세요.

2. 열 이름과 단위 연결

단위를 자동 변환하지 않습니다. 장비 판정값은 측정값에 연결하지 마세요. 시각·LOT·Recipe·규격은 이 버전에서 검증하지 않습니다.

3. 측정값이 평소 범위를 벗어나면?
