저장된 분석 보고서 — 실제 정상 개발자료의 탐색 기록

기존 Python 실행 보고서를 읽기 전용으로 표시합니다. 새 분석 실행·실시간 센서 연결·원본 시계열 재생이 아닙니다. 아래 CSV 시연이나 가상 로봇 이송 시뮬레이션의 결과와 합치지 않습니다.

IMAD-DS 정상 개발자료 7파일·2기록 그룹의 1,043개 창(52.15초)에서 얻은 경보 9·0·3건은 탐색 결과이며 방법 간 우열이나 현장 탐지 성능을 입증하지 않습니다. 전체 아카이브 해시·실제 휴대전화·스크린리더·이상 탐지 성능은 미검증입니다.

2 파일 입력 — 파일마다 따로 검증합니다

UTF-8 CSV, 파일당 최대 5MB·20,000행(약 3초 @ 6.7 kHz). 원본 IMAD-DS Parquet 전체 구간은 이 브라우저 시연의 범위를 넘습니다. 시각 역전·중복·숫자가 아닌 시각, 열 이름 불일치, cadence 불일치가 있으면 그 파일은 무효로 처리하고 보정하지 않습니다.

SYNTHETIC · 합성 시연 아래 파일은 이 페이지가 정수 난수로 만든 합성 데이터입니다. 로봇 측정값이 아니며 결과는 계산 규칙을 보여 줄 뿐입니다. 예상 SHA-256 칸은 생성기가 만든 바이트의 해시이므로 자기 일관성 확인일 뿐 출처 증명이 아닙니다.

3 창 분할과 보류 사유

파일 사이를 이어 붙이지 않습니다. gap이 걸친 창, 최소 표본 미달 창, NaN·무한대가 있는 창, |값|이 1,000,000 g를 넘는 창은 평가 불가로 남기고 지우거나 보간하지 않습니다. 표본이 없는 연속 창은 개수와 함께 한 칸으로 표시합니다.

■ 평가 가능■ 시각 공백(gap)■ 표본 부족■ NaN·무한대■ 범위 밖(|값| > 1,000,000 g)■ 부분 창(계산 안 함)

4 경보 활동 — 성능이 아닙니다

reference로 중심·척도를, calibration으로 임계값을 정하고, evaluation은 어떤 조정에도 쓰지 않습니다. 정상 라벨만으로 안정 정상이라고 판단하지 않으므로 결과는 오탐률이 아니라 경보 활동입니다.

이 화면이 하지 않는 것

  • Python 백엔드를 실행하거나 서버에 연결하지 않습니다. 같은 계약의 Python 모듈은 #173으로 main에 반영됐지만 이 화면의 백엔드로 연결되지 않았습니다. 이 화면의 계산은 고정된 합성 입력에서 그 모듈과 결과를 맞춰 본 브라우저 구현입니다.
  • 공개 IMAD-DS 원본을 이 화면에서 받거나 실행하지 않습니다. 위 실제 분석 표는 기존 오프라인 SPC 보고서의 읽기 전용 표시입니다. 정상 개발자료 7파일·2기록 그룹의 1,043개 창(52.15초)에서 Shewhart 9건·EWMA 0건·CUSUM 3건은 경보 활동이며, 이상 탐지 성능이나 방법 간 우열을 입증하지 않습니다. EWMA 0건도 이상 탐지 성공을 뜻하지 않습니다. 전체 아카이브 해시·실제 휴대전화·스크린리더·이상 탐지 성능은 미검증입니다.
  • onset·종료 라벨이 없으므로 검출 지연·재현율·놓침률·오탐률은 항상 null입니다. 합성 시연에 수준 변화를 넣었어도 계산하지 않습니다.
  • 50 ms 창 수는 독립 세션 수가 아닙니다. 경보는 원인이나 고장 진단이 아니며 장비 연결·정지·제어를 하지 않습니다.
  • 하중·배경 조건이 같다는 라벨은 동작·속도·세션이 같다는 뜻이 아닙니다.
  • 해시 일치는 바이트가 같다는 뜻일 뿐 출처 인증이 아닙니다. 이 화면은 해시를 계산한 바로 그 바이트를 디코딩하지만, 브라우저 CSV 디코더는 신뢰 경계로 남습니다. 모델 artifact 결속과도 별개입니다.
  • |값| > 1,000,000 g 범위 제한은 수치 overflow를 막기 위한 상한이며 센서 규격이 아닙니다. 표본이 없는 연속 창은 한 칸으로 압축해 보여 주므로 화면과 계산량은 시간 길이가 아니라 표본 수에 비례합니다.
