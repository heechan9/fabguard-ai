위에서는 과거 생산 자료를 분석했어요. 여기서는 팹 투어에서 본 장비의 역할과 화면 읽는 법을 배워 봅니다. 일반 공정 원리를 설명하는 도식과 가상 알람 체험이며, 해당 장비나 SECOM 분석과 연결되어 있지 않아요.

이 장비들은 무엇을 만드는 걸까요?

반도체 재료판인 웨이퍼에 층과 무늬를 만들고, 두께를 줄이거나 작은 칩으로 나누는 장비들이에요. 각 카드의 ‘자세히 보기’를 펼치면 역할과 필요한 데이터를 볼 수 있어요.

무늬를 만드는 기본 흐름감광액 바르기 → 위치 맞추고 빛 쬐기 → 현상하기원리 이해를 위해 건조·가열 등 중간 단계를 생략했어요. 투어 장비의 실제 운전 순서나 레시피가 아닙니다.

감광액 도포·현상 (PR Track) 자세히 보기

사진의 ‘PR track’ 표기, 원형 처리부와 노즐·배관을 참고했어요. 각 사진 속 처리부가 도포용인지 현상용인지는 개별 확인이 필요합니다. PR은 Photoresist의 약어예요.

막 두께와 균일도를 판단하려면 실제 막 두께 측정값이 필요해요. 회전속도·시간·재료 기록도 함께 수집해야 합니다. 사진으로 두께나 불량을 계산하지 않아요.

어느 부분이 제거되는지는 감광액 종류와 공정에 따라 달라요. 도식은 특정 양성·음성 레지스트 레시피를 재현하지 않습니다.

플라즈마 식각 (ICP Etcher) 자세히 보기

사진의 사용 일지와 영상의 ‘ICP Etcher’ 표기를 확인했어요. ICP는 유도결합 플라즈마(Inductively Coupled Plasma)를 뜻합니다. 사진 속 장비의 정확한 모델이나 식각 성능은 확인하지 않았어요.

식각 깊이·형상은 실제 측정이 필요해요. 압력·고주파 전력(RF)·가스 유량·온도와 공정 단계의 시간 기록은 분석에 필요한 후보 자료입니다. 화면에 보이는 설정값만으로 식각 결과를 예측하지 않아요.

장비의 역할을 알았다면, 이제 상태 화면을 읽어 봐요

① 목표와 실제를 따로 보기

장비 화면에는 설정값(SET)과 현재 표시값(ACT 또는 Monitor)이 나란히 보였어요. 목표를 입력했다는 사실만으로 실제 공정이 그 값에 도달했다고 볼 수는 없어요.

확인할 기록: 측정 시각, 단위, 설정값, 실제값, 허용 범위와 공정 단계. 대기 중인지 처리 중인지에 따라 의미가 달라져요. 측정값이 없으면 정상 대신 ‘확인 필요’로 남깁니다.

② 어떤 작업인지 연결하기

생산 묶음(LOT), 작업 조건 묶음(Recipe), 실행 회차(Run)는 서로 다른 정보예요. 같은 조건을 여러 번 실행하거나 여러 생산 묶음에 적용할 수 있어요.

아래 체험은 DEMO-LOT-01 · DEMO-RECIPE-A · DEMO-RUN-01이라는 가상 식별자를 사용해요.

③ 알람을 확인하고 이력 남기기

투어 사진의 알람 목록에는 용액 부족과 폐액 넘침 메시지, 경고·알람 구분, 발생 시각이 보였어요. 알람을 읽었다는 기록과 원인이 해소됐다는 기록은 따로 필요해요.

장비 알람만으로 생산품 불량이나 원인을 확정하지 않아요.

발생 순서대로 남는 기록

먼저 위의 가상 사례를 선택하세요.

    조건 해소는 버튼으로 정한 가정이에요. 실제 센서 확인·정비·운전 허가를 뜻하지 않으며, 생산품 품질은 이 체험에서 판정하지 않습니다.

    정비 알림과 ‘예상 처리 장수’는 어떻게 읽나요?

    연마기 사진에는 구성부의 READY 표시와 정비 주기를 지났다는 메시지가 함께 있었어요. READY 하나로 장비 전체가 정상이라거나 운전해도 된다고 결론낼 수는 없습니다.

    같은 화면의 Estimated Wafers는 장비가 표시한 추정 항목이에요. 계산 방식·적용 조건·정확도는 확인하지 않았습니다. FabGuard가 검증한 AI 예측이 아니며, 실제 남은 수명을 확정하는 값으로 쓰지 않아요.

    소모품 분석을 하려면 날·휠 식별자, 사용량과 단위, 정비·교체 시각과 사유, 해당 실행의 품질 검사 결과를 함께 모아야 해요. 사진에 보이는 Blade Replacement의 Lot ID도 의미를 확인하기 전에는 웨이퍼 생산 묶음과 같은 ID로 연결하지 않습니다.

    저장된 레시피와 실제 실행 기록은 달라요

    추가 영상에는 Deep Si Etcher와 MUC-21 표기가 보이고, 화면에는 레시피 목록과 날짜가 다른 펌프 경고들이 함께 보여요. 이 자료는 레시피 관리와 경고 이력을 설명하는 사례입니다. 목록만으로 어떤 조건을 실제 실행했는지, 경고가 현재도 지속되는지는 알 수 없어요.

    재현 가능한 기록에는 레시피 ID와 버전, 승인 상태, 실제 실행에 사용한 조건 사본, Run의 시작·종료 시각과 결과가 필요해요. 파일 이름이나 수정 날짜만으로 승인된 버전이라고 판단하지 않습니다. 이는 FabGuard의 기록 설계에 참고할 항목이에요.

    경고 이력도 발생·해소 시각과 확인 기록을 구분해야 해요. 다른 화면에 보이는 Buzzer off는 소리 관련 조작 표기이며, 경고 확인·원인 해소와 같은 뜻으로 취급하지 않습니다.

    배경 참고 · MMC에 수록된 Sumitomo 장비 소개(2007)에는 여러 MUC-21 기반 구성이 등장해요. 사진 속 세부 구성이나 식각 깊이·성능은 이 자료로 확정하지 않습니다.

    잘 만들어졌는지는 무엇으로 확인할까요?

    지금까지는 장비의 역할과 상태를 살펴봤어요. 결과를 확인하려면 알고 싶은 것에 맞는 측정이 필요해요. 높이 차이, 얇은 막의 두께, 재료 특성, 휨은 서로 다른 질문입니다.

    현재 상태: 실제 측정 결과는 아직 없어요아래는 측정 방법 안내예요. 사진과 영상에서 수치·스펙트럼·측정 지도를 추출한 분석 결과가 아닙니다.

    높이 차이와 막 두께가 항상 같은 것은 아니에요

    사진에는 Veeco Dektak 150과 3D profiler 표기가 보여요. 접촉식 프로파일러는 표면의 높이 변화와 단차를 살펴보는 장비예요. 높이 차이를 막 두께로 해석하려면 비교할 기준면과 시료 구조가 맞아야 합니다.

    스캔 위치·길이·측정 조건·교정 기록과 원본 높이 데이터를 함께 남겨야 해요. 위치를 맞추는 십자 표시 화면만으로 측정 완료나 전체 표면의 정상 여부를 판단하지 않아요.

    일반 원리 참고 · Bruker 접촉식 프로파일러 — 다른 세대의 장비 설명이며 사진 속 장비의 사양 검증 자료는 아니에요.

    빛으로 구한 두께에는 재료와 층 구조의 가정이 들어가요

    사진의 Nanospec 표기와 광학 측정 장면을 참고했어요. 정확한 장비 모델은 확인하지 않았습니다. NanoSpec 계열의 분광 반사 측정은 파장별 반사광과 재료·층 구조 모델을 이용하는 방식이에요.

    분석하려면 반사광 원본, 기준 시료·교정 기록, 재료의 광학 특성, 층 구조, 측정 위치와 모델 적합 상태가 필요해요. 모니터에 숫자가 보인다는 사실만으로 두께의 정확성을 검증할 수는 없습니다. 이 계산은 미래의 불량을 예측하는 AI와도 다른 개념이에요.

    일반 원리 참고 · NNCI NanoSpec 측정 안내 — 동일 설치 장비의 모델 확인 자료는 아니에요.

    적외선 스펙트럼은 재료 특성을 해석하는 자료예요

    사진에는 VERTEX 70v 표기가 보여요. 푸리에 변환 적외선 분광(FTIR, Fourier Transform Infrared Spectroscopy)은 적외선과 물질의 상호작용을 이용해 화학 결합 특성을 살펴보는 방법입니다.

    실제 해석에는 원본 스펙트럼, 배경 측정, 시료 준비와 측정 방식, 비교할 기준 자료가 필요해요. 장비 외관만으로 시료 성분·오염·순도나 합격 여부를 판정하지 않습니다.

    일반 원리 참고 · Bruker 적외선 분광 안내

    휨을 재는 것과 막의 응력을 계산하는 것은 달라요

    사진에는 k-Space의 MOS Ultra-Scan 표기가 보여요. 이 장비의 MOS는 여러 빔을 쓰는 광학 센서(Multi-beam Optical Sensor)를 뜻해요. 반사된 레이저 배열을 이용해 위치별 곡률과 휨을 살펴봅니다.

    막이 내부에서 당기거나 미는 정도인 응력은 곡률 자료에 물성·두께와 모델 가정을 더해 계산해요. 공정 전후 곡률, 기판·막 두께, 기판의 탄성 특성, 교정과 모델 적용 조건을 확인해야 합니다. 외관 사진에서 휨·응력 값을 만들거나, 휨만으로 불량을 확정하지 않아요.

    일반 원리 참고 · k-Space 곡률·휨 측정 · 응력 해석과 측정 오차

    측정 결과를 어느 웨이퍼·공정에 연결해야 할까요?

    사진 속 칸이 있는 보관함은 웨이퍼를 담는 카세트를 설명하는 참고예요. 같은 보관함에 있다는 사실만으로 모두 같은 생산 묶음이거나 같은 처리를 받았다고 볼 수는 없어요.

    개별 웨이퍼 ID, 생산 묶음(LOT), 보관함 ID와 칸 번호(Slot), 공정 실행 회차(Run)를 따로 기록해요. 웨이퍼가 이동하면 보관 위치 이력도 갱신해야 합니다.

    측정 기록에는 장비·시각·위치·방법·단위·원본 파일·교정 정보를 붙여야 해요. 평가 기준과 비교 가능한 측정 결과를 확보하기 전까지 FabGuard에서는 ‘미측정·확인 필요’로 구분합니다. 현재 사진만으로 이 추적 관계가 확인된 것은 아니에요.

    장비를 둘러싼 운영 기록

    사람·시료·전원도 함께 관리해요

    팹 운영에는 입실 절차, 시료 보관, 장비를 지원하는 전원 설비도 포함돼요. 이번 현장의 게시물과 전원반은 어떤 관리 기록이 필요한지 살펴보는 사례입니다.

    누가 사용할 수 있나요?

    Open Lab 게시물은 역할별 복장과 입실 절차를 안내하고 있어요. 복장 색상만으로 장비 조작 권한을 판단할 수는 없습니다.

    기록 설계에 참고하기

    사용자 역할, 교육 이수, 장비별 사용 승인, 적용할 절차의 버전과 유효 기간을 구분해요. 사진 속 복장·착용 순서는 해당 시설의 사례이며 모든 팹의 공통 규칙으로 적용하지 않아요. 실제 입실·작업은 해당 시설의 최신 안내에 따릅니다.

    이 시료는 누구의 것인가요?

    게시물에는 시료·시약의 이름, 반입·보관 날짜, 사용자와 지정 장소를 관리하는 항목이 있어요.

    보관 이력에 연결하기

    시료 ID, 담당자, 반입 시각, 승인된 위치와 이동 이력을 구분해 기록할 수 있어요. 시약은 물질 식별자와 보관 조건도 따로 관리해야 합니다. 이 화면은 관리 항목을 설명하며, 실제 재고·사용자·승인 기록은 연결되어 있지 않아요.

    장비 주변에도 전기가 필요해요

    MCC-604 전원반에는 에어샤워·패스박스 등의 회로 표기와 계기가 보여요. 이는 공정 장비 자체와 구분할 지원 설비의 사례예요.

    전류와 전력 사용량 구분하기

    계기의 전압·전류와 차단기 용량은 누적 전력 사용량(kWh)과 다른 정보예요. 전력 사용량 분석에는 측정 구간, 시각, 누적 유효전력량과 검증된 회로·설비 연결 정보가 필요합니다.

    탄소배출량까지 계산하려면 사용 전력에 적용할 지역·기간·산정 방식에 맞는 배출계수도 필요해요. 사진의 바늘 위치나 0.00 표시로 사용량·탄소배출·장비 정상을 추정하지 않습니다. 현재 에너지 데이터와 이 전원반의 연결도 확인되지 않았어요.
