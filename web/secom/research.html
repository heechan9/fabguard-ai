프로젝트 소개반도체 분석검증과 한계

FabGuard 플랫폼 · SECOM 모델 평가 연구 기록 (플랫폼의 일부) FabGuard는 반도체·제조 데이터 전처리, 공정 품질, 모델 평가, 기존 장비 데이터 점검 기능을 포함하는 플랫폼이며, 이 화면은 그중 SECOM 전처리·모델 평가 실험 하나만 다룹니다. 기존 반도체 분석 화면을 바꾸지 않는 별도 연구 기록입니다. 화면의 수치는 미병합 Draft PR #170의 고정 head e7cdc47b 산출물을 그대로 옮긴 것이며, 이 화면을 만들며 실험을 다시 실행하지 않았습니다.

SECOM · TRAINING-ONLY DEVELOPMENT EXPERIMENT

학습 구간 안에서 전처리를 비교했지만, 개선은 입증되지 않았습니다

결측 처리 방식 4가지와 고정 모델 3개(+기준 Dummy)를 학습 구간의 날짜 블록 폴드에서만 비교했습니다. 운영·데모 모델은 바꾸지 않았고, 이후 392행 시험 구간은 읽지도 점수 내지도 않았습니다.

실험 설계 — 결과를 보기 전에 고정

폴드별 학습·검증 크기와 검토 예산 (날짜가 겹치지 않는 확장형 블록)
폴드학습 행 / 불량검증 행 / 불량검증 기간상위 10% 검토 수

검토 예산은 폴드마다 ceil(0.10 × 검증 행)입니다. 포착 분모는 그 폴드 검증 구간의 모든 불량입니다. 세 폴드는 학습 구간이 겹치는 종속 폴드라 표준편차는 신뢰구간이 아닙니다. 날짜 블록은 LOT·장비 분리를 대신하지 못합니다(해당 ID가 SECOM에 없음).

비교한 결측 처리 4가지

impute_only

590개 열 전체, 학습 폴드 중앙값 대치만. 지시변수·필터 없음.

filter_only

학습 폴드 기준 결측 50% 초과·관측값 1종 이하·완전 중복 열 제거 후 중앙값 대치.

current

위 필터 + 중앙값 대치 + 결측 지시변수. 현재 전처리 기준선이며 V1 모델 선택의 재현이 아닙니다.

current_plus_row_missing

current에 행마다 원본 590열의 결측 개수를 더한 새 특징.

모델: L1 로지스틱(C=0.1), 랜덤 포레스트(120 trees, depth 8), HistGradientBoosting(100 iterations, lr 0.05), 기준선 Dummy(prior). 튜닝·탐색 없음. 특징은 익명 측정변수이며 이 화면은 특정 공정 변수 이름을 붙이지 않습니다.

13개 후보 결과 — 모두 표시

세 폴드 결과 (AP 평균 ± 표본표준편차, 포착은 세 폴드 예산의 합산)
모델결측 처리AP 평균 ± SDAP 최소–최대포착 / 불량폴드별 포착합산 포착률

AP는 scikit-learn average precision입니다. 평균 AP가 높은 후보가 같은 검토 예산의 포착에서도 앞서지는 않습니다. Dummy는 동점 정렬이 임의라서 포착 범위와 무작위 동점 기대값을 함께 봐야 합니다.

미리 정한 비교 — 같은 모델 안에서만

평균 AP 변화와 포착 수 변화 (같은 폴드·같은 예산)
모델비교평균 AP 변화포착 변화읽는 법

후기 폴드는 불량이 11건뿐이라 포착 1건이 재현율을 약 9%p 움직입니다. 이 차이들은 모델 교체나 품질 필터 제거의 근거가 아닙니다.

오늘 강의 내용과 FabGuard SECOM의 대응

강의 자료는 이 저장소나 화면에 올리지 않았습니다. 아래는 주제만 요약한 것이며, 교재 예시 수치는 FabGuard 결과가 아닙니다. 강의 내용 전체를 적용했거나 플랫폼을 업그레이드했다는 뜻이 아닙니다. “구현함”은 이 화면이 실제로 보여 주는 것만 가리킵니다.
