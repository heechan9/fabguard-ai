# SECOM 성능·검증 근거 검토

검토 기준과 확인한 최신 main은 동일한 `627542999ef229a89b2c4cb592ae2a03e41bade0`이다. 기존 웹의 RTE 완료 표시는 이미 수정돼 중복 변경하지 않았다. 새 실험은 `experiment/temporal-ranking-20260925`에만 두며 V1·Phase1 정본과 운영 모델은 교체하지 않는다. 작업 식별자의 날짜는 실험 ID이며 실행 환경·정확한 코드 커밋은 manifest에 남긴다.

## 결론

- **표시·근거 개선:** README/안내의 RTE 완료 상태와 품질 경고를 정본에 맞춤. RF 전체 중요도와 개별 설명을 분리. 이것은 예측 성능 향상이 아니다.
- **차이 불명확:** V1 Logistic과 RF의 AP·동일 예산 포착 우열은 지표마다 다르며 paired 구간이 0을 포함한다. RF 우월 주장 불가.
- **점추정 악화:** 두 신규 가설 모두 기존 RF보다 후기 AP·40건 포착이 낮다. 불확실성까지 고려하면 두 후보 모두 차이 불명확이며, 통계적으로 확정된 악화라고도 하지 않는다. 개선으로 판정된 후보는 없다.
- **독립 검증 없음:** 노출된 SECOM 392건의 후속 탐색 결과다. 재분할·bootstrap은 독립 검증을 복구하지 않는다.

## 비교 계약과 재현

공식 원본 SHA-256 확인, 저장된 train/test ID와 순서 일치, 시간순 학습 1,175건·후기 392건(불량 24, 정상 368), seed 20260822. V1의 학습 반복 층화 CV가 선정한 L1 C=.01 및 RF 120 trees/depth=None/leaf=8/sqrt를 그대로 재학습했다. sklearn 1.8.0/numpy 2.3.5/pandas 2.2.3에서 세 모델의 저장 AP가 1e-12 이내 일치하고 RF 392개 점수도 1e-12 이내 일치했다. 원본 V1/Phase1 모든 파일 해시는 실행 전후 동일하다.

AP는 average precision이며 PR 곡선 사다리꼴 면적과 혼용하지 않는다. 점수 내림차순·동점 sample_id 오름차순. K는 ceil(비율×392): 20/40/79건. 포착률=발견 불량/24, 정밀도=발견 불량/K, Lift=정밀도/(24/392), 정상 점검수=K−발견 불량이다.

## 개선 실험: 선정과 결과 분리

사전 프로토콜 커밋 `ed2b521`, 실행 코드 커밋 `91b18ad`. H1은 상관된 약한 신호 보존을 위한 L2 C=.1, H2는 잡음 감소를 위한 학습 폴드 내부 ANOVA F 상위40개 RF다. 추가 후보 탐색 없음. 학습 1,175건 내부 3개 확장 검증은 학습 587/783/979건, 검증 각각196건(불량4/9/4). 모든 경계 train_end < validation_start를 검사했다.

| 후보 | 학습 시간순 평균 AP | 학습 평균 Top10 포착률 |
| --- | --- | --- |
| Dummy prior | 0.028912 | 24.07% |
| H1 Logistic L2 | 0.044205 | 11.11% |
| H2 RF 변수40 | 0.102861 | 27.78% |
| V1 Logistic L1 | 0.077520 | 27.78% |
| V1 RF | 0.051319 | 11.11% |

학습 평균 AP로 H2를 선택하고 선택 JSON·임계값을 후기 예측 이전에 저장했다. 그러나 후기 H2 AP=.080090, Top40=3건으로 기존 RF .093477/5건보다 낮다. H1도 .087640/3건이다. 후기 결과를 보고 후보·설정을 바꾸지 않았다.

- **시간순 검증:** V1은 외부 분할이 시간순이지만 내부 선택은 반복 층화 CV여서 미래가 내부 학습에 섞일 수 있다. 이번 내부 검증은 과거→미래만 허용한다. 작은 실패 수와 학습 길이 차이가 남는다.
- **결측/변수 선택:** 50% 결측 필터, 상수/중복 제거, 중앙값·결측 indicator, Logistic 스케일링과 H2 변수 선택은 각 학습 폴드에만 fit. 정본 전처리 정의는 바꾸지 않았다. ANOVA는 단변량이라 상호작용 신호를 놓칠 수 있다.
- **불균형:** Logistic balanced / RF balanced_subsample만 사용, 검증 분포는 그대로 유지. 전체 데이터 과표집 없음. 가중 학습 점수를 보정된 불량 확률로 단정하지 않는다.
- **임계값:** 학습 시간순 OOF F2 최대(동점 높은 threshold)로 정한 RF 기준은 .140961. 후기 TP=6/24지만 FP=63, 총69건 점검으로 예산40과 다르다. H2 .118317은 TP12/FP183, 총195건을 점검한다. 재현율 상승을 동일 예산 성능 향상으로 계산하지 않으며 AP/Top-K는 임계값 변경으로 좋아지지 않는다. OOF는 서로 다른 fitted 모델 예측을 합치므로 재학습 모델에의 임계값 이전도 불확실하다. 운영 임계값은 유지한다.

## 설명과 독립 검증

`priority_table()`의 RF 상위5 중요 변수는 모든 생산 건에 동일한 전체 불순도 중요도다. 화면에 전체 범위와 동일 목록임을 명시했고 미확인 scope는 개별 설명으로 표시하지 않는다. Logistic의 변환 입력×계수는 로짓 공간의 선형 기여도이며 실제 센서 원인/인과관계가 아니다. 개별 설명을 새로 구현하지 않았다. 필요하면 별도 실험에서 학습 background 고정, 합산 일치, 반복 안정성과 상관 변수 민감도를 검증한 뒤 도입한다. 설명 문구 수정은 예측 성능 개선과 별도로 보고한다.

확보된 repository 자산에는 적합한 독립 제조 평가 데이터가 없다. SECOM 재다운로드·태양광 연동·합성 SMT는 대체물이 아니다. 입력 이름590개만으로 의미·단위 호환을 인정하지 않는다. 다른 KAMP 공정은 별도 모델/분할/라벨 계약을 사용한다. 확보 조건은 `docs/INDEPENDENT_DATA_VALIDATION.md`에 구체화했다.

## 권고와 증거 위치

운영 반영 추천은 완료 상태/품질 경고의 통일, 설명 범위 수정, 비교표·한계 문서화뿐이다. 새 모델, OOF 임계값, 새 개별 설명은 운영에 반영하지 않는다. 기존 디자인·지도·라우트·기능을 유지한다.

실험 브랜치 `experiments/temporal-ranking-20260925/`에 PROTOCOL.md, run.py, test_study.py와 results의 원점수·학습검증·예산별 표·임계값·시간구간·bootstrap·manifest를 보관한다. 실행: `PYTHONPATH=src python experiments/temporal-ranking-20260925/run.py`. 원본 SECOM·모델 바이너리는 추가 배포하지 않는다. main 문서에는 설명과 기준 3개 모델의 비교 CSV만 반영하며, 원래 `results/v1`, `results/phase1`을 갱신하지 않는다.

출판 기록: 프로토콜·실행 코드의 위 커밋은 실행 전 로컬 git에서 고정한 SHA다. HTTPS push 인증을 사용할 수 없어 결과를 GitHub connector로 별도 커밋하여 게시한다. 원격 커밋 SHA와 로컬 실행 SHA를 혼동하지 않도록 `LOCAL_COMMIT_HISTORY.txt`와 manifest를 함께 보관한다.
